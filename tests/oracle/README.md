# Oracle parts

Reference parts whose volume, surface area, centre of mass and bounding box are known in closed
form. Kernel and feature tests compare against these values, never against values the code
produced itself or values from commercial CAD (`skills/chamfera-tests/SKILL.md`).

The first parts arrive with kernel rung K4 (`docs/kernel-ladder.md`): a box, a plate with holes,
a cylinder, a cone and a torus. Each part has a script and its analytic values with the
derivation.
